Back up Paimon.moe first

Paimon.moe's Settings → Import replaces all existing local data, not just wishes. Export a fresh backup before importing. Without an existing JSON, this export contains only wish-* fields and does not preserve characters, inventory, settings, or other accounts. With an existing JSON, these are preserved from that backup, and only the matching account's supported wish histories are merged.

Paimon displays timestamps as supplied. Choose your account's server UTC offset if you need its banner timeline to align: Europe +01:00, America -05:00, or Asia +08:00. Other offsets can change how Paimon groups wishes near banner boundaries.
